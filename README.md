# PyTorch Regression

Учебный проект по регрессии на PyTorch. Нейросеть получает десять числовых признаков и предсказывает одно непрерывное значение. В проекте реализованы подготовка тензоров, Dataset и DataLoader, обучение, валидация, сохранение и загрузка весов.

## Данные и задача

Используется встроенный набор [Diabetes из scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_diabetes.html): **442 примера и 10 признаков**. Цель — количественный показатель прогрессирования заболевания через год после исходного обследования. Это задача регрессии, а не классификация наличия диабета.

`load_diabetes()` возвращает уже центрированные и масштабированные признаки. Отдельно скачивать CSV не нужно: данные поставляются с scikit-learn. В репозитории копия набора не распространяется; описание и первоисточник доступны в документации загрузчика.

## Архитектура и обучение

```text
10 числовых признаков
        ↓
Linear(10, 64) → ReLU
        ↓
Linear(64, 32) → ReLU
        ↓
Linear(32, 1)
        ↓
Предсказанное число
```

У модели **2817 обучаемых параметров**. На выходе нет функции активации, ограничивающей диапазон предсказания.

| Настройка | Значение |
| --- | --- |
| Разбиение | Train 354 примера / validation 88 примеров |
| Seed разбиения | 42 |
| Batch size | 16 |
| Эпохи | 100 |
| Функция ошибки | MSELoss |
| Оптимизатор | AdamW |
| Learning rate | 0.001 |
| Устройство | CPU |

`train.py` создаёт `TensorDataset`, разделяет его через `random_split` и обучает сеть. Каждые десять эпох выводятся ошибка последнего тренировочного батча (`Loss`) и средняя по батчам за эпоху (`Avg_Loss`). После обучения скрипт считает validation loss и сохраняет **последние** веса в `regression_model.pt`.

`predict.py` создаёт такую же архитектуру, загружает веса и выводит два числа: предсказание для первого объекта набора и его реальное целевое значение. Это демонстрация загрузки модели; первый объект может относиться к train, поэтому один такой пример не является независимой оценкой качества.

## Запуск на Windows

Проверялось на Python 3.13.2, PyTorch 2.15.0+cpu и scikit-learn 1.9.1. Все команды выполняются из корня проекта:

```powershell
git clone https://github.com/Awuiga/pytorch-regression.git
cd pytorch-regression
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

python train.py
python predict.py
```

Сначала нужно запустить обучение: готовые веса в Git не включены. Повторный запуск `train.py` начинает обучение заново и перезаписывает локальный файл весов. Существующие чужие checkpoints загружать не следует.

## Ограничения и воспроизводимость

- Seed 42 фиксирует разбиение, но не начальные веса и не порядок обучающих батчей. Поэтому loss и предсказания при повторном обучении могут отличаться.
- `Avg_Loss` и validation loss в исходном коде — средние арифметические ошибок батчей. Последний батч меньше остальных, но имеет такой же вес в среднем. Эти числа немного отличаются от MSE, усреднённой по всем объектам.
- Отдельного test split, ранней остановки, выбора лучшей эпохи, MAE и R² в текущем коде нет. Validation оценивается один раз после 100 эпох.
- Используется стандартное масштабирование всего встроенного набора до разбиения. Для более строгой проверки новых данных преобразования стоит обучать только на train.
- Это небольшой учебный эксперимент. Он не оценивает пригодность модели для практических медицинских решений.

Исходная логика обоих скриптов сохранена. Результаты проверочного запуска описаны в [VERIFICATION.md](VERIFICATION.md). Основные зависимости закреплены по рабочему окружению; установка в полностью чистое окружение отдельно не проверялась. Отдельная открытая лицензия на код пока не выбрана автором.
