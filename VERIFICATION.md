# Проверка публикации

14 ноября 2026 года опубликованная копия проверена отдельно от рабочего проекта.

- Окружение: Windows, Python 3.13.2, PyTorch 2.15.0+cpu, scikit-learn 1.9.1.
- `train.py` выполнен полностью: 100 эпох, валидация и сохранение весов.
- Средняя ошибка train на последней эпохе: `2807.8060660984206`; validation loss: `3175.9488321940103`. Обе величины вычислены исходным скриптом как средние ошибок батчей, а не пообъектная MSE.
- Затем выполнен `predict.py` с весами этого проверочного запуска. Предсказание для первого объекта: `192.1774139404297`, реальное значение: `151.0`. Этот объект не выбран как независимый тест.
- Случайная инициализация не фиксировалась, как и в исходном коде; другой запуск может дать другие числа. Подбор параметров по validation не выполнялся.
- Синтаксис исходников проверен, структура вычислений совпадает с оригиналами. Удалены только лишние пробелы в концах строк.
- Хеши исходных `train.py`, `predict.py` и `regression_model.pt` после проверки не изменились. Рабочие веса не перезаписывались.
- В исходной папке `.git` отсутствовал. Публикация подготовлена в отдельном репозитории с новой историей.

В Git входят код, README, зависимости и этот отчёт. Окружение, веса и рабочие логи исключены. Установка зависимостей в полностью чистое окружение отдельно не проверялась.
